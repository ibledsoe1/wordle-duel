# Wordle Duel
Wordle Duel is a multiplayer game where two players try to solve as many Wordle puzzles they can before the timer runs out. The player who gets the most words wins.

# How it works
- Two players join a match and receive the same sequence of word puzzles to solve
- A countdown starts the match, and a 3 minute timer starts
- Each player tries to solve the word puzzles on their own, the rules are the same as regular wordle:
  - 5 letter words
  - 6 tries to get word
  - Each guess reveals hints:
    - Green -> Correct letter, correct placement
    - Yellow -> Correct letter, incorrect placement
    - Gray -> Incorrect letter
- Whoever has the most words solved after the timer is up wins
